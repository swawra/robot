# Robojam Robot Code 
This repo contains the master copy of the simplified robot code, with all pygame references removed allowing this to run at the terminal, rather than in X11.

Copy these files to `/home/pi/robot`:

  `robot.py` 
  `robotlib.py`
  `init.sh`

then run

`chmod 755 /home/pi/robot/init.sh`

This repo also contains 
* the instruction pack for the teams (ask the school to print 1-2 copies per team)
* the facilitator notes
* the scoreboard xls
